# Security Policy

## Supported version

Only the latest GitHub release is supported.

## Reporting

Please report security concerns privately through GitHub's security advisory feature. Do not include destination names, backup paths, usernames, hostnames, serial numbers, credentials, or private logs in a public issue.

## Safety boundary

Time Machine Watchdog is a local, read-only status reporter. It does not repair backups, validate restore integrity, install persistence, or transmit data. Treat its result as a prompt to inspect and test your backup—not as proof of recoverability.
